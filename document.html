โครงสร้างพื้นฐานของ HTML

HTML ทุกฉบับบจะมีโครงสร้างพื้นฐานที่ประกอบด้วยแท็กหลักๆ ดังนี้

index.html 
<!DOCTYPE html>
<html lang="th">
<head>
<meta charset="UTF-8">
<meta name="viewport"
content="width=device-width, initial-scale=1.0">
<title>หน้าแรกของฉัน</title>
</head>

<body>
<h1>ยินดีต้อนรับสู่เว็บไซต์ของฉัน</h1>
<p>นี่คือหน้าแรกของฉันในภาษา HTML</p>
</body>
</html>
<!DOCTYPE html>

บอกเบราว์เซอร์ว่าเป็นเอกสาร HTML5 เพื่อให้ประมวลผลและแสดงผลหน้าเว็บได้อย่างถูกต้องตามมาตรฐานล่าสุด

<html>

รูทของเอกสาร (Root element) ที่ครอบคลุมเนื้อหาทั้งหมดของหน้าเว็บ และมักใช้กำหนดภาษาของหน้าเว็บด้วยแอตทริบิวต์ lang

<head>

ส่วนเก็บข้อมูลทางเทคนิค (Metadata) เช่น ชื่อเรื่อง (Title), การกำหนดรหัสตัวอักษร (Charset), และการเชื่อมโยงไฟล์ภายนอกอย่าง CSS หรือ JavaScript

<body>

ส่วนที่แสดงเนื้อหาจริงๆ บนหน้าจอที่ผู้ใช้มองเห็น เช่น ข้อความ, รูปภาพ, วิดีโอ, ปุ่มกด และลิงก์ต่างๆ
