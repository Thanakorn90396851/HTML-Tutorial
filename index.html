Basic HTML

เรียนรู้เว็บไซต์เบื้องต้น
{ Website Development Basics }

ก้าวแรกสู่การเป็นนักพัฒนาเว็บไซต์ เริ่มต้นด้วยการเรียนรู้โครงสร้างพื้นฐานด้วย HTML
อย่างถูกต้องและเป็นระบบ พร้อมแบบฝึกหัดที่ให้คุณลงมือทำจริง

index.html
<!DOCTYPE html>
<html lang="th">
<head>
<title>Learning HTML</title>
</head>
<body>
<h1>สวัสดีนักพัฒนาเว็บไซต์ทุกคน</h1>
<p>ยินดีต้อนรับสู่เว็บไซต์สำหรับนักพัฒนาด้วย HTML</p>
</body>
</html>

สิ่งที่คุณควรเรียนรู้ในการเขียน HTML

เนื้อหาถูกออกแบบมาให้เข้าใจง่าย เน้นการลงมือปฎิบัติจริงในแต่ละบทเรียน

MODULE 1

Headings (หัวเรื่อง)

เรียนรู้การจัดลำดับความสำคัญของเนื้อหาผ่านแท็ก H1 ถึง H6 เพื่อโครงสร้างเว็บที่ถูกต้องและดีต่อ SEO

MODULE 2

Text Formatting

การตกแต่งข้อความเบื้องต้น ตัวหนา ตัวเอียง ขีดเส้นใต้ และการจัดย่อหน้า

MODULE 3

Links (การเชื่อมโยง)

สร้างจุดเชื่อมต่อไปยังหน้าเว็บอื่นๆ หรือเว็บไซต์ภายนอกเพื่อสร้างเครือข่ายข้อมูล

MODULE 4

Images (รูปภาพ)

แทรกรูปภาพเพื่อความน่าสนใจ พร้อมเรียนรู้การใช้แอตทริบิวต์ alt เพื่อการเข้าถึง
